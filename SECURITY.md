# Security Policy

## Supported versions

The latest published `1.x` release receives security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, email **hello@hackmyip.com** with:

- a description of the issue
- steps to reproduce
- the potential impact

We aim to acknowledge reports within 72 hours and will keep you updated on the fix. Responsible disclosure is appreciated.

## Scope

This package is a thin HTTP client for the public [hackmyip.com](https://hackmyip.com) API. It requires no API keys or credentials and stores no secrets. Reports about the client's request handling, input validation, or dependency surface are in scope.
